# gaze-capture · 屏幕前眼球行为捕捉

用**普通 RGB 网络摄像头**（无红外、无专用眼动仪）实时估计注视屏幕位置，判定三类基本眼球行为：

- **注视点停留 fixation** —— 视线在某点保持超过阈值
- **视线移动 saccade** —— 两次注视之间的快速跳转
- **持续凝视 sustained gaze** —— 长时间锁定同一目标

并输出可复核的会话报告：报告里的每个数字都能从导出的逐帧数据独立复算。

## 这个项目承诺什么、不承诺什么

**承诺**（个人 9 点校准后，头部固定）：

| 指标 | 底线 | 目标 |
|---|---|---|
| 3×3 分区命中率 | 85% | 90% |
| 角度误差 | ≤4° | 2–4° |

**明确不承诺**：瞳孔直径绝对值、微眼动、扫视峰值速度与幅度、眨眼精确起止、<100 lux 暗光下的任何指标、跨用户开箱即用。

能判"在看屏幕哪一大块、停了多久、何时跳走"，**不能判"在看哪个字"**。

## 硬前提

以下任一项不满足，精度承诺不成立——这不是建议，是数学前提：

- 摄像头 **1280×720 起**（720p 下虹膜直径约 22–26px，这是全部精度的来源）
- **能锁定曝光/增益**（自动曝光跳变会直接毁掉虹膜边缘，比分辨率更重要）
- 桌面照度 **300–750 lux**，光源在屏幕侧上方且**不与摄像头同轴**
- 视线与镜头光轴夹角 **≤30°**，眼-镜头距离 50–70cm
- **必须做**首次 9 点校准（30–40 秒）

## 隐私

- 默认**不录视频、不落盘任何原始帧**，只存特征与坐标
- 数据只在本机 `%LOCALAPPDATA%` 下的会话目录，可一键清除
- 导出包**不含任何摄像头原始帧与人脸图像**；允许导出以屏幕内容为画布的轨迹图
